# AndroidAPS

AndroidAPS with Ottai support, without paywalls, WeChat subscription, or other restrictions.

支持欧态的 AndroidAPS 构建版本，无付费墙、无需微信公众号订阅等限制。

## How to Build / 构建方法

### English

1. Fork this repository: [https://github.com/mokurin000/AndroidAPS/fork](https://github.com/mokurin000/AndroidAPS/fork)
2. Go to the **Actions** tab
3. Select **Android CI**
4. Click **Run workflow**, then confirm again
5. Wait for about 15 minutes
6. Open the workflow run
7. Download the artifact `aaps.zip`

### 中文

1. Fork 本仓库：[https://github.com/mokurin000/AndroidAPS/fork](https://github.com/mokurin000/AndroidAPS/fork)
2. 打开 **Actions** 页面
3. 选择 **Android CI**
4. 点击 **Run workflow** 并再次确认
5. 等待约 15 分钟
6. 打开对应的运行记录
7. 下载构建产物 `aaps.zip`
